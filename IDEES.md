# 💡 Idées pour la suite

Liste des fonctionnalités à ajouter un jour à l'appli « Mes tâches ».
(Rien d'obligatoire — juste un carnet d'idées.)

## Idées faciles
- [ ] 🌗 Bouton **mode clair / sombre**
- [ ] 📅 Une **date d'échéance** par tâche
- [ ] 🗂️ Des **catégories** ou des **couleurs** pour trier les tâches
- [ ] ↕️ **Réordonner** les tâches par glisser-déposer

## Idées un peu plus avancées
- [ ] 🔔 Rappels / notifications
- [ ] ✏️ Modifier le texte d'une tâche existante
- [ ] 🔍 Rechercher / filtrer les tâches
- [ ] ☁️ Synchronisation entre plusieurs appareils

---
*Pour cocher une idée faite : remplace `[ ]` par `[x]`.*
